# Her0 Brand Guideline Skill

## Visão Geral

Este é o brand guideline oficial da **Her0** — a evolução da MicroFactory Labs (MFL). Her0 é uma marca com dois produtos: **her0.io** (plataforma self-service guiada por IA para first-timers virarem founders) e **her0.studio** (venture studio hands-on com equity partnership para domain experts).

Use este skill para garantir consistência em todas as comunicações: pitch decks, documentos, landing pages, posts, emails, materiais internos e qualquer output visual ou textual da marca.

**IMPORTANTE:** Este skill SUBSTITUI o mfl-brand-book-skill. A paleta MFL (amarelo #FFD000 / preto #1A1A1A) NÃO deve ser usada em materiais Her0. A transição é completa — sem herança visual.

---

## Quando Usar Este Skill

Ative SEMPRE que precisar:
- Criar apresentações, pitch decks ou one-pagers da Her0
- Desenvolver landing pages, sites ou interfaces com a marca Her0
- Escrever copy para redes sociais, emails ou materiais de venda
- Produzir documentos internos (MOUs, contratos, propostas)
- Garantir consistência visual e de tom em qualquer material
- Montar materiais para ventures do portfólio (Obra Ninja, Projeto Azeitona, GovPass)
- Criar conteúdo para LinkedIn, newsletter ou blog
- Gerar brand assets (logos, favicons, badges, banners)
- Avaliar se um material está on-brand ou off-brand

## 1. Narrativa

### A Tese

Na era da IA, a barreira para empreender desabou. Ferramentas que exigiam equipes inteiras cabem na mão de uma pessoa. Milhões de profissionais vão migrar de empregados para empreendedores — não por ideologia, mas por oportunidade.

O problema: a maioria nunca empreendeu. O playbook do Vale do Silício existia, mas estava trancado em aceleradoras de elite e networks fechados.

Her0 existe pra resolver isso.

### HER0 = HERO + ZERO

- Todo founder é um herói. Toda jornada começa do zero.
- O '0' não é vazio — é o ponto de partida. É a coragem de começar sem saber tudo.
- O 'Her' carrega 'hero' sem o 'o' — porque o zero JÁ é o 'o'. O número completa a palavra.

### Tagline Principal

**"Everyone can be a her0 too."**

3 camadas de significado:
1. **Fonética:** "her0 too" falado em voz alta soa como "her0.io" — a tagline É o domínio
2. **Numérica:** "every ONE" ecoa o "0" da marca — 1 e 0, os dígitos que constroem tudo em binário
3. **Semântica:** Qualquer pessoa pode ser herói — a tese da plataforma numa frase

### Dois Produtos, Uma Marca

| Produto | Domínio | Pra Quem | O Que Faz |

## 3. Logo

### Anatomia

O logo Her0 é tipográfico, em **caixa baixa: her0**. O elemento central é o '0' (zero) que substitui o 'O' de 'Hero'.

| Elemento | Especificação |
|----------|---------------|
| **Tipografia** | Sans-serif geométrica bold (Space Grotesk Bold ou equivalente). Lowercase: her0. |
| **O zero (0)** | Cor Signal (#00E5A0). Fundo arredondado (pill shape). Barra diagonal interna (slashed zero) cortando do canto inferior-esquerdo ao superior-direito. |
| **Letras h-e-r** | Cor Snow (#FFFFFF) em fundo escuro. Cor Ink (#0D1117) em fundo claro. Sem tratamento especial — o zero é que se destaca. |
| **Barra diagonal** | A ASSINATURA VISUAL DA MARCA. Cor do fundo (Snow em dark, Ink/Snow em light). Ângulo ~45°. Espessura proporcional ao peso da tipografia. |
| **Fundo do zero** | Background pill/rounded-rect em Signal (#00E5A0) que contém a barra diagonal. Cria contraste e destaca o zero como elemento independente. |

### A Barra Diagonal (Slashed Zero)

A barra diagonal resolve 3 problemas:
1. Garante que leia como NÚMERO, não como letra
2. Cria elemento gráfico reconhecível mesmo em favicon de 16px
3. A barra em ângulo sugere movimento — seta sutil apontando pra cima e pra frente (a trajetória do herói)

**A barra diagonal NUNCA pode ser removida. Sem ela, o zero vira O e a marca perde a tese.**

### 7 Variantes

| Variante | Descrição | Quando Usar |
|----------|-----------|-------------|
| **her0 (lowercase dark)** | Letras Snow + zero Signal com fundo pill + barra diagonal Snow. Fundo Ink. | Padrão principal. Landing pages, decks, redes sociais. |
| **her0 (lowercase light)** | Letras Ink + zero Signal com fundo pill + barra diagonal Snow. Fundo Snow/Cloud. | Documentos, emails, impressos em papel branco. |
| **HER0 (uppercase dark)** | Mesmo tratamento do zero, letras uppercase Snow. | Contextos formais: contratos, headers legais. |
| **H0 (monograma)** | Apenas H + zero com barra diagonal. Compacto. | Espaços reduzidos, avatares, assinatura rápida. |
| **0 isolado (favicon)** | Zero Signal com fundo pill arredondado (rounded square Ink). Barra diagonal Snow. | Favicon, ícone de app, bullet de marca, marcador de seção. |
| **her0.io** | Logo her0 + '.io' em peso light/regular, tamanho menor, cor Slate. | Landing page da plataforma, materiais específicos do .io. |
| **her0.studio** | Logo her0 + '.studio' em peso light/regular, tamanho menor, cor Slate. | Landing page do studio, materiais específicos do .studio. |

### 6 Regras do Logo

1. **Área de respiro:** Mínimo 50% da altura do logo em cada lado. Nunca encostar em bordas.
2. **Tamanho mínimo:** 80px digital / 20mm impresso. Abaixo disso, usar favicon (0 isolado).
3. **O que NUNCA fazer:** Distorcer, rotacionar, mudar cores fora do sistema, remover a barra diagonal, usar outline no zero, adicionar sombra/gradiente.
4. **O ponto (.io / .studio):** Pode ser estilizado — tamanho reduzido, cor Signal, círculo preenchido.
5. **Lowercase é default:** 'her0' sempre minúsculo exceto em contextos legais/formais.
6. **O zero é sagrado:** A barra diagonal dentro do zero NUNCA pode ser removida.

## 4. Paleta de Cores

### Racional (Sean Adams — 7 Princípios Aplicados)

A paleta foi definida aplicando os 7 princípios de cor de Sean Adams (Designer's Dictionary of Color) à narrativa da marca:

| Princípio Adams | Como foi aplicado |
|-----------------|-------------------|
| 1. Cor transmite antes de ser lida | MFL usava amarelo/preto = energia industrial. Her0 precisa transmitir SEGURANÇA primeiro — o first-timer tem medo. Base Ink (navy) acolhe antes de energizar. |
| 2. Significado cultural varia | Signal (#00E5A0) = verde-menta. Verde = permissão (semáforo), crescimento. Funciona globalmente sem conflito cultural. |
| 3. Contraste cria hierarquia | Ink escuro + Signal vívido = contraste máximo. O olho sabe onde olhar. |
| 4. Temperatura define tom emocional | Base COOL (Ink = confiança do sherpa) + acentos WARM (Flare = coragem do herói). Cool-dominant com sparks de calor. Inverso do MFL. |
| 5. Saturação controla volume | Base dessaturada (Ink, Slate, Cloud = sussurro). Accent hipersaturado (Signal, Flare = grito cirúrgico). |
| 6. Limitar a paleta | 2 primárias (Ink + Signal) + 1 warm accent (Flare) + 5 neutras + 4 semânticas = 12 cores total. |
| 7. Testar em contexto real | Cada cor pensada pra landing page dark, UI light, pitch deck, LinkedIn, email, docs. |

**A mudança fundamental:** MFL vendia pra EXPERTS confiantes (amarelo = energia). Her0 vende pra INICIANTES inseguros (navy = segurança, menta = permissão de avançar). O first-timer precisa sentir "pode vir, é seguro" antes de "vá, corra, construa".

### Cores Primárias

| Nome | Hex | Uso | Adams |
|------|-----|-----|-------|
| **Ink** | `#0D1117` | Fundo dark premium. O céu noturno de onde heróis nascem. | Blue: honestidade, lealdade, autoridade. Dessaturado = acolhimento. |
| **Signal** | `#00E5A0` | Accent primário. O sinal verde: pode avançar. CTAs, badges, o '0' no logo. | Mint: fresh, modern, lightness with personality, clean without cold. |
| **Flare** | `#FF6B4A` | Accent quente. A coragem do herói. CTAs de ação, urgência. Usar com moderação. | Coral: warm, inviting, accessible, human. |

### Cores Neutras (família Slate)

| Nome | Hex | Uso |
|------|-----|-----|
| **Snow** | `#FFFFFF` | Fundo light mode. Limpo, editorial. |
| **Cloud** | `#F6F8FA` | Cards, seções alternadas. Off-white com undertone azul. |
| **Mist** | `#E6EDF3` | Divisores, bordas sutis. |
| **Slate** | `#8B949E` | Texto secundário, labels, descrições. |
| **Steel** | `#484F58` | Texto terciário em light mode. |
| **Carbon** | `#C9D1D9` | Texto principal em dark mode. |
| **Ink Soft** | `#161B22` | Cards em dark mode. Elevação 1. |
| **Ink Mid** | `#21262D` | Elevação 2 em dark mode. Hover states. |

### Cores Semânticas

| Nome | Hex | Uso |
|------|-----|-----|
| **Valid** | `#2EA043` | Sucesso, validado, rodando. Stage-gate aprovado. |
| **Warn** | `#D29922` | Atenção, warning. "Valide antes de avançar." |
| **Fail** | `#F85149` | Erro, problema, dor. "Não passou no gate." |
| **Info** | `#58A6FF` | Informação, links, dicas. |

### Proporção de Uso

50% Ink/Snow (dominante) + 30% Cloud/Slate/Mist (suporte) + 12% Signal (accent primário) + 8% Flare (accent quente)

**Signal é destaque cirúrgico, NUNCA fundo universal.** Flare é reservado para momentos de alta energia/urgência.

### CORES QUE NÃO USAMOS MAIS

| Cor MFL | Hex | Status |
|---------|-----|--------|
| Amarelo MFL | `#FFD000` | **DESCONTINUADO.** Não usar em nenhum material Her0. |
| Preto MFL | `#1A1A1A` | **SUBSTITUÍDO** por Ink `#0D1117`. |
| Cinza MFL | `#F0F0EA` | **SUBSTITUÍDO** por Cloud `#F6F8FA`. |
| Teal MFL | `#1B998B` | **SUBSTITUÍDO** por Signal `#00E5A0`. |

**O '0' no logo e materiais:** Sempre Space Grotesk Bold com barra diagonal interna (slashed zero) e fundo pill Signal. A barra diagonal é a assinatura visual — sem ela, o zero vira O e a marca perde a tese.

## 6. Sistema de Layout

### Alternância Ink / Snow (Sanduíche)

| Modo | Fundo | Texto | Accent | Quando Usar |
|------|-------|-------|--------|-------------|
| **Ink** | #0D1117 | Snow/Carbon | Signal | Abertura, fecho, hero sections, CTAs principais |
| **Snow** | #FFFFFF | Ink/Steel | Signal + Flare | Conteúdo, features, detalhes |
| **Signal** | #00E5A0 | Ink | — | Blocos de impacto, highlight boxes |
| **Flare** | #FF6B4A | Snow | — | Urgência, CTA quente (usar com moderação) |

### Componentes Visuais

| Componente | Descrição |
|------------|-----------|
| **Barra Signal topo** | 2-3px full-width Signal (#00E5A0) no topo de toda página/slide. Assinatura Her0. |
| **Card + accent bar** | Fundo Cloud + barra lateral 4px Signal à esquerda (light). Fundo Ink Soft + accent Signal (dark). |
| **Highlight box** | Fundo Signal (#00E5A0) com texto Ink. Destaque máximo. Usar com moderação. |
| **CTA quente** | Fundo Flare (#FF6B4A) com texto Snow. Ações de alta urgência. |
| **Badge status** | Pill shape: Valid (#2EA043) = rodando. Warn (#D29922) = atenção. Fail (#F85149) = erro. |
| **O '0' como ícone** | Zero com barra diagonal + fundo pill arredondado Signal. Favicon, bullet, marcador de seção. |
| **Linha de progresso** | 2px que transita: Ink → Signal → Valid conforme etapas avançam. |

## 10. Checklist de Qualidade

Antes de publicar qualquer material Her0, validar:

1. Logo lowercase 'her0' com zero Signal (#00E5A0), barra diagonal interna, fundo pill arredondado
2. Paleta nova aplicada — NENHUMA cor MFL (sem #FFD000, sem #1A1A1A)
3. Base dark = Ink (#0D1117), NUNCA preto puro
4. Signal como accent primário — NUNCA como fundo universal
5. Flare usado com moderação — CTAs quentes, urgência, coragem
6. Tom: empoderador + acessível. O herói é o FOUNDER.
7. Diferenciação clara her0.io vs her0.studio
8. Alternância Ink/Snow nos decks (sanduíche)
9. Barra Signal no topo de toda página (2-3px)
10. Tipografia: Space Grotesk (títulos) + Inter (corpo). Fallback: Calibri
11. Zero linguagem de curso/coaching/guru
12. Fundadores como dupla (Leo + Fernando). Nunca um sem o outro.
13. Cada menção a etapa inclui OUTPUT concreto — não promessa abstrata
14. Neutras são Slate family (undertone azul) — nunca cinza quente
