Read these three first

1 · R1 — how the autonomous mode keeps the rule "no frozen contract, no squads". Squads build against a contract frozen as a draft; this review ratifies it into v1.0; a contradiction that changes the CONTRACT re-enters the squads as an amendment. The alternative was to review before squads write (praxya's order). This is the one default that changes how a run feels.
2 · The guard fix that was never installed (cases C-E9-07, C-E9-08). The named-run fix from commit 7fcff27 lived only in the root copy; the plugin copy Claude Code actually runs never had it. It is mirrored now (uncommitted, authorization A-4) and v4 makes the rule robust: the guard resolves a run by its package folder, not by a path convention.
3 · The renderer's escaping case (C-E2-12). The renderer being ported can be broken out of with an upper-case </SCRIPT> inside an embedded note. v4 fixes it and asserts it.

The three honest states of this review

good · you answer

Contradictions are threaded through the affected files, the CONTRACT is re-frozen as v1.0, KICKOFF's pinning block is re-pinned, and the five terminals in SESSIONS.md can be opened. The build runs overnight; the morning report names what to read first.

legitimately empty · you answer nothing

Nothing irreversible happens. The CONTRACT stays v1.1-draft, the machine refuses to hand off a draft, no session opens, no commit or tag is made. The package waits on disk.

misconfigured · a contradiction changes the CONTRACT

The affected squad's PRD and epics are re-planned against the amended contract (v1.1 → v1.2) before any session opens. This page is re-rendered as a v2 with a "what changed since v1" section and your rulings carried forward. No "Approve" is offered for a changed contract until that round completes.

Known limitations of this planning run

This run executed on the 3.0.1 machine (17 states), so the decisions and freeze gates were recorded as coordinator defaults pending this review rather than through the new v4 states. The 3.0.1 reconcile embedded in the handoff lint scans the v3 folder by literal; the coordinator reconciled the v4 package through the lint's own per-epic declared-versus-counted check. The HTML pages of this run are hand-rendered following the renderer's contract (stamps in the page head, brand badge, glossary panel); the v4 renderer replaces them and the markdown stays canonical. The run's own state file keeps its legacy name until the named-runs epic lands.
