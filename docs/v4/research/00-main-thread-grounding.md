Options: (a) `v1.0-draft` counts as frozen for the guard; `freeze` after planReview bumps to `v1.0`; (b) run the review BEFORE parallelPlanning (review the design + CONTRACT, then squads write against a frozen v1.0, then a light second look at the epics). Stream B analyses; coordinator decides at synthesis. Leaning (b): it keeps Rule 1 intact and matches how the praxya run actually went (research report approved → CONTRACT frozen → squads).
